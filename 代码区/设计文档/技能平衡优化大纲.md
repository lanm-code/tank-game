# 技能平衡与特效优化大纲

> 状态:✅ 全部实施完成(2026-08-27)—— P0 数值平衡 ✅ / P1 机制补强 ✅ / P2 特效 ✅ / P3 验证 ✅(梯度断言+全量回归 8 套)
> 追加需求: 技能满级后不再出现在卡池(已有逻辑)+ 满级卡显示 "MAX" 徽标 + HUD 图标满级显示 MAX ✅;技能栏移至左下角 ✅
> 起因: 实机整体试玩后反馈 —— 部分低稀有度技能收益反超高稀有度技能;史诗/传说缺乏存在感;技能缺少对应特效。
> 目标: 建立"稀有度越高收益越高"的清晰梯度,史诗/传说做成机制质变,并给每个技能配极简风格特效。

## 二、平衡原则与度量

1. **梯度铁律**(每次拾取等效 DPS/生存增益):
   - 普通 1 层 ≈ **+25%~40%**
   - 稀有 1 层 ≈ **+45%~65%**
   - 史诗 1 层 ≈ **+70%~90% 或独特机制**
   - 传说 = **机制质变**(改变玩法),不再用纯数值衡量
2. **多弹减伤**: 分裂类技能(双发/三发)每发伤害打折,总增益封顶(避免一家独大)。
3. **控制要控开火**: 减速类技能同时降低敌人攻速,否则 CC 是假的。
4. **周期技能要快**: 自动触发类(静电场/时停/核弹)周期压缩到"每场战斗能触发 2 次以上"。
5. **特效服从极简**: 白/灰 + 坦克本色为唯一彩色,粒子小而少,不发光不拖屏(遵守《极简塔防》改造精神)。

## 四、特效设计方案(极简风格)

新增粒子生成函数(挂在现有 `entities/particle.py` 体系),全部小粒子、无光晕、短时长:

| 技能 | 特效 | 实现挂点 |
|------|------|----------|
| 冰霜弹头 | 命中时白色小冰晶(6~8 粒,0.4s) | `tank.take_damage` slow 分支 |
| 加速弹头 | 子弹短拖尾(白色细线加长) | `bullet.draw` 速度判断 |
| 弹射强化 | 弹射瞬间白圈小扩散 | `bullet.update` ricochet 分支 |
| 双发/三发 | 无(弹幕本身是表现) | — |
| 能量护盾 | 格挡时白圈扩散+盾牌闪烁 | `tank.take_damage` shield_chance 分支 |
| 吸血子弹 | 绿色"+"粒子从敌人飞向玩家(3 粒) | `game._update_bullets` 吸血分支 |
| 死亡爆破 | 白环扩散(半径=爆炸半径,0.3s) | `game._on_enemy_killed` 爆破分支 |
| 静电场 | 白色折线闪电(3 段)+命中火花 | `game._update_skill_effects` 雷击分支 |
| 不屈意志 | 金色(坦克本色黄)护盾破碎粒子 | `tank.take_damage` last_stand 分支 |
| 狙击之眼 | 命中瞬间细白瞄准线(0.15s) | `game._update_bullets` dead_eye 分支 |
| 轨道炮 | 子弹贯穿白光束拖尾(2 倍弹长) | `bullet.draw` railgun 分支 |
| 时间静止 | 触发时全屏边缘灰圈收缩 + 敌人闪灰 | `game._update_skill_effects` chrono 分支 |
| 末日核弹 | 全屏白闪(0.3s)+ 中心大爆炸粒子 | `_trigger_doomsday` |
| 不死凤凰 | 复活时火羽粒子柱(坦克本色红/黄) | `_check_end_conditions` 复活分支 |
| 狂战士 | 坦克红光脉冲,血量越低越强 | `tank.draw` berserk 分支 |
| 幻影军团 | 半透明幻影坦克(40% alpha)绘制 | `game.render` / `tank.draw` |
| 磁铁 | 道具被吸附时小拖尾 | `pickup.update` 磁吸分支 |

## 六、风险与备注

- 多弹减伤后,双发/三发的旧数值测试需同步更新(测试脚本里的弹数/散布断言不变,伤害断言新增)。
- 冰霜"降攻速"需要给 `Tank.take_damage` 加 fire_rate 乘区,注意与眩晕、地块减速共存(取更强不覆盖)。
- 幻影复制弹幕 = 幻影子弹按玩家当前 multi_shot/pierce/ricochet 发射,注意性能(每轮 ≤1 轮齐射)。
- 特效全部走现有 `particles` 列表生命周期,不引入新渲染层。
