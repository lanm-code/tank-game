# 坦克游戏大改任务清单

## 诊断发现

| 问题 | 根因 | 影响 |
|------|------|------|
| 贴图白底 | 坦克 PNG 无 alpha 通道 (`noalpha`)，角像素全白，白色像素占 56-72%。`convert_alpha()` 对无 alpha 源图无效 | 坦克/子弹贴图显示白方框 |
| 坦克太小 | 屏幕 1280×720，TILE=40，坦克 36-44px，原图 1024×1820 被压缩 20-40 倍 | 细节全丢 |
| 界面简略 | HUD 单色扁平，无渐变/动画/粒子特效 | 观感差 |
| 白边去除失败 | `_strip_white_bg` 用 numpy 处理 alpha，但源图无 alpha 通道 | 白边依然存在 |

---

## 改动项

### A. 贴图白底彻底修复（核心）
**当前**：`assets._strip_white_bg` 基于 numpy 操作 alpha → 源图无 alpha 通道，无效

**方案**：改用 `set_colorkey((255,255,255), RLEACCEL)` + 背景填充黑/透明 + `convert()` 转 alpha 源
- 对每个贴图先 `fill((0,0,0))` 作为透明底，再 `set_colorkey(white, RLEACCEL)` 去除白色
- 保留 numpy 版本作为兜底（对部分白边非纯白的贴图）
- 子弹贴图同样处理
- 验收：截图中坦克/子弹周围无白色方框

### B. 拉大游戏页面 + 放大坦克（核心）
**当前**：SCREEN=1280×720，TILE=40，TANK=36-44px
**目标**：SCREEN=1920×1080，TILE=64，TANK=80-96px

| 常量 | 当前 | 目标 | 备注 |
|------|------|------|------|
| SCREEN_WIDTH | 1280 | 1920 | 1.5× |
| SCREEN_HEIGHT | 720 | 1080 | 1.5× |
| TILE_SIZE | 40 | 64 | 1.6× |
| MAP_COLS | 32 | 30 | 略减，避免地图过大 |
| MAP_ROWS | 18 | 16 | 略减 |
| TANK_WIDTH | 36 | 72 | 2× |
| TANK_IMG_SIZE | 44 | 88 | 2× |
| BULLET_IMG_SIZE | 27→radius*3 | radius*4 | 加大 |

- 同步调整：碰撞框、生成点、HUD 位置、结算页位置
- 使用 `pygame.SCALED` + `vsync=1` 自动适配任意窗口
- 验收：坦克占约 1.5 格宽度，细节可辨

### C. 坦克细节还原
**当前**：44px 压缩 20+ 倍，炮塔/履带/炮管全糊
**方案**：
1. 使用原图（1024×1820）→ 缩放至 176×176（2× 显示尺寸）→ 渲染时 `smoothscale` 到 88×88
2. 分层渲染：车身（旋转）+ 炮管（独立旋转）+ 履带动画
3. 炮塔用过程化绘制兜底（若贴图缩放后质量仍差）
4. 履带动画：左右履带交替偏移 2px，带纹理
5. 炮管：从车身中心伸出，独立旋转
- 验收：坦克炮管/履带/车身可辨，有运动感

### D. UI 美化
1. **主菜单**：
   - 背景加动态网格 + 粒子
   - 按钮渐变填充 + 悬停发光
   - 坦克 3D 预览加旋转动画
   - 标题加霓虹辉光
2. **HUD**：
   - 玩家面板加渐变背景
   - 血条加流光动画
   - 分数/击杀数字跳动动画
   - 波次提示浮窗
3. **结算页**：
   - 大标题动画（缩放浮现）
   - 数字滚动计数
   - 背景粒子
4. **升级页**：
   - 卡片翻转效果
   - 选中卡片发光
- 验收：所有 UI 元素有过渡动画

### E. 渲染优化
1. 背景网格线改为半透明 + 霓虹色
2. 墙壁纹理：砖墙加线条，钢墙加金属高光
3. 草地加摇曳动画
4. 水面加波纹动画
5. 子弹拖尾加长加颜色渐变
6. 击杀爆炸加粒子散射
7. 屏幕震动加模糊叠加
- 验收：整体观感接近截图效果

### F. 代码结构优化
1. 渲染分层：`Background → Walls → Tanks → Bullets → HUD → Overlay`
2. 所有绘制函数统一用 `camera_x/y` 偏移
3. 图片加载加 LRU 缓存
4. 输入处理集中化
5. 游戏状态机清晰化

### G. 兼容性
- 保留小屏支持：窗口可拖动缩放
- 保留 720p 作为最低分辨率
- 所有资源路径向上查找

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| 大图缩放后质量仍差 | 中 | 中 | 过程化兜底 |
| 分辨率变化导致布局错位 | 高 | 高 | 全局搜索坐标，常量驱动 |
| 白边无法完全去除 | 低 | 中 | set_colorkey + 手动描边 |
| 性能下降 | 中 | 中 | LRU 缓存 + 限频渲染 |
