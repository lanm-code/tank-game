## 一、项目概述 (Executive Summary)

### 1.1 项目定位
**「钢铁前线：霓虹坦克战」** — 一款科幻风格的 2D 俯视角坦克大战网页游戏。  
融合了《坦克世界》的策略走位、《合金弹头》的火力升级、《霓虹深渊》的赛博朋克视觉，以及《吸血鬼幸存者》的Roguelike随机掉落机制。

### 1.2 核心卖点 (USP)
| 卖点 | 说明 |
|------|------|
| 🎮 多模式玩法 | 剧情闯关、无尽生存、Boss Rush、双人本地合作 4 大模式 |
| 🔥 搞怪弹药系统 | 鸡蛋弹、奶蛋弹、飞刀弹 3 种特色弹药（与素材库匹配） |
| 👹 巨型Boss战 | 每 5 关一个巨型 Boss，多阶段攻击模式 |
| 🎵 趣味语音包 | 奶龙、神鹰黑手哥、蔡徐坤 等网红语音彩蛋 |
| 🎨 霓虹科技风 | 赛博朋克 UI + 粒子特效 + 屏幕震动反馈 |
| 🎲 Roguelike要素 | 随机掉落技能、每局成长路线不同 |

### 1.3 参考爆火玩法
- **经典FC坦克大战**: 砖墙/钢墙/基地保护机制 —— 致敬情怀
- **坦克动荡 (Tank Trouble)**: 子弹弹射机制 + 狭窄地形策略
- **Shell Shockers**: 第一人称蛋形射击的趣味感 → 转化为「蛋形弹药」搞怪设定
- **Brawl Stars**: 3v3 模式 + 技能超级充能系统
- **Vampire Survivors**: 无尽模式 + 经验升级 + 被动技能树

## 二、技术栈选型 (Tech Stack)

> 原则: **零构建工具依赖**，纯原生即可运行，方便 Solo Builder 快速开发

| 层级 | 技术选择 | 理由 |
|------|----------|------|
| **前端框架** | `HTML5 + CSS3 + Vanilla JavaScript (ES6+)` | 无需编译，直接打开 `index.html` 即可运行 |
| **渲染引擎** | `HTML5 Canvas 2D API` | 性能足够支撑 100+ 实体同屏，粒子特效流畅 |
| **游戏循环** | `requestAnimationFrame` + 固定时间步长 (Fixed Timestep) | 保证不同帧率设备上手感一致 |
| **状态管理** | 简单有限状态机 (FSM) + 全局 `GameState` 对象 | 轻量，无需引入 Redux/Pinia |
| **UI 框架** | 原生 DOM + CSS Grid/Flex + 霓虹风格 CSS 变量 | 与 Canvas 分层渲染，UI 不卡游戏帧率 |
| **音频系统** | `HTML5 Audio` + `Web Audio API` (可选) | 支持背景音乐 + 音效 + 趣味语音包 |
| **数据持久化** | `localStorage` | 存档最高分、解锁进度 |
| **像素资源** | 使用现有素材 PNG + Canvas `drawImage` | 无需额外素材生成工具 |
| **打包部署** | 单 HTML 文件 / 静态资源目录，一键部署 Vercel | 零后端依赖 |

> ⚠️ 不使用任何游戏引擎（Phaser/Pixi.js），降低学习成本，完全可控。

### 3.2 核心数据结构 (Data Models)

#### GameState 全局状态 (单例)
```javascript
const GameState = {
  // 游戏阶段: 'menu' | 'playing' | 'paused' | 'gameover' | 'victory'
  phase: 'menu',
  // 当前模式: 'story' | 'endless' | 'bossrush' | 'coop'
  mode: 'story',
  // 当前关卡 (1-30)
  level: 1,
  // 玩家数据
  players: [
    {
      id: 1,
      x: 100, y: 600,         // 位置
      angle: 0,               // 炮管朝向 (弧度)
      hp: 100, maxHp: 100,    // 血量
      shield: 0,              // 护盾
      speed: 3,               // 移动速度
      fireRate: 500,          // 射击间隔(ms)
      damage: 20,             // 基础伤害
      bulletType: 'egg',      // 'egg' | 'milky_egg' | 'knife'
      superCharge: 0,         // 大招充能 0-100
      // 被动技能buff列表
      buffs: ['double_shot', 'pierce', 'ricochet'],
      score: 0,
      kills: 0
    }
  ],
  // 波次
  wave: {
    current: 1,
    total: 5,
    enemiesLeft: 8,
    spawnTimer: 0
  },
  // Boss 状态 (当前关无Boss则为null)
  boss: null,
  // 基地血量 (经典模式)
  baseHp: 100,
  // 最高分记录
  highScore: 0,
  // 屏幕震动参数
  shake: { magnitude: 0, duration: 0 }
};
```

## 四、核心玩法设计 (Gameplay Design)

### 4.1 四大游戏模式

| 模式 | 解锁条件 | 玩法说明 | 胜利条件 |
|------|----------|----------|----------|
| 🎯 **剧情闯关 (Story)** | 默认解锁 | 30 关渐进难度，每5关一个Boss。保护基地不被摧毁。 | 击杀本关所有敌人 |
| ♾️ **无尽生存 (Endless)** | 通关第10关解锁 | 无限波次，敌人越来越强，看你能撑多少波。随机掉落技能。 | 存活越久分越高 |
| 👹 **Boss Rush** | 击败第一个Boss解锁 | 连续挑战 6 个巨型Boss，无杂兵干扰。 | 依次击败所有Boss |
| 👥 **双人合作 (Coop)** | 通关第5关解锁 | 本地双人分屏？不，同屏2P合作！WASD + 箭头键双玩家。 | 共同通关或波次 |

### 4.2 操作方案 (双玩家同屏)

| 按键 | 玩家 1 (蓝色坦克) | 玩家 2 (红色坦克) |
|------|-------------------|-------------------|
| 移动上 | `W` | `↑` |
| 移动下 | `S` | `↓` |
| 移动左 | `A` | `←` |
| 移动右 | `D` | `→` |
| 射击 | `空格 Space` | `Enter 回车` |
| 切换弹药 | `Q / E` | `, / .` |
| 释放大招 | `Shift` | `RShift 右Shift` |
| 暂停 | `Esc` / `P` | 同步暂停 |

> 💡 移动方式: **坦克式转向** (Tank Control) —— 按左右键原地旋转车身，按前后前后移动，增加还原度。可选设置切换为「直接方向移动」。

### 4.3 弹药系统 (3种特色弹药 + 大招)

与素材库 `子弹种类/` 目录严格对应：

| 弹药类型 | 图标 | 伤害 | 射速 | 特性 | 解锁方式 |
|----------|------|------|------|------|----------|
| 🥚 **鸡蛋弹 (Egg)** | 鸡蛋.png | 20 | 500ms | 基础弹，碰到障碍爆炸 | 默认拥有 |
| 🥛 **奶蛋弹 (MilkyEgg)** | 奶蛋.png | 15 | 350ms | 穿透 2 个敌人，留下减速液体区域 | 第 3 关掉落解锁 |
| 🔪 **飞刀弹 (Knife)** | 刀.png | 45 | 900ms | 超高伤害，可弹射 3 次（打墙反弹） | 第 7 关掉落解锁 |

#### 大招系统 (Super Skill)
击杀敌人积累充能槽（Super Charge），满100点释放：
- **玩家1大招**: 🛡️「盾墙冲击」—— 全身护盾 + 向前发射 8 方向弹幕，持续 3s
- **玩家2大招**: 💥「天女散蛋」—— 向四周抛出 20 枚随机弹药，全屏轰炸
- **效果**: 释放时播放语音包随机一条（战胜语音池）

### 4.4 地图与障碍类型 (4种墙体)

| 墙体类型 | 颜色/外观 | 血量 | 特性 |
|----------|-----------|------|------|
| 🧱 **砖墙** | 红色像素砖纹 | 1 | 可被子弹摧毁，经典坦克大战标配 |
| 🔩 **钢墙** | 银灰色金属 | ∞ | 免疫普通弹，仅飞刀弹/大招可破 |
| 🌿 **草丛** | 绿色半透明 | ∞ | 坦克进入隐身（降低50%被发现概率），子弹可穿过 |
| 💧 **水域** | 蓝色波纹 | ∞ | 坦克不可通行，子弹可穿过，飞行类Boss可越过 |

### 4.5 Roguelike 升级掉落系统

击杀敌人 15% 概率掉落道具，通关每关必选 1 个三选一升级：

## 五、敌人与 Boss 设计 (Enemies & Bosses)

### 5.1 普通敌人类型 (6 种)

| 敌人名称 | 外观参考 | 行为模式 | 威胁等级 |
|----------|----------|----------|----------|
| 🟢 **侦察兵 (Scout)** | 绿色坦克 | 速度快，血量低，直线冲锋射击 | ★☆☆ |
| 🟡 **炮兵 (Artillery)** | 黄色坦克 | 远距离狙射，移动慢，伤害高 | ★★☆ |
| 🔴 **重甲 (Heavy)** | 红色坦克 | 高血量，近战撞击，三连发射 | ★★★ |
| ⚫ **幽灵 (Ghost)** | 黑色坦克 | 可穿越砖墙，隐身突袭 | ★★☆ |
| 🔵 **工程师 (Engineer)** | 蓝色坦克 | 可修复附近队友，优先击杀 | ★★☆ |
| 🟣 **精英 (Elite)** | 紫色渐变 | 随机组合以上 2 种能力 | ★★★★ |

### 5.2 Boss 系统 (6 个巨型 Boss)

**每 5 关一个 Boss，多阶段攻击模式 (血量每下降 33% 进入下一阶段)**

#### Boss 1: 「蛋王」 Egg Emperor (第 5 关)
- **外观**: 巨型鸡蛋外壳坦克，头顶皇冠
- **阶段 1 (100%-66%)**: 环形发射 8 方向鸡蛋弹
- **阶段 2 (66%-33%)**: 召唤 4 个小蛋兵，自身发射追踪弹
- **阶段 3 (33%-0%)**: 疯狂模式 —— 蛋雨从天而降，本体冲撞玩家
- **击败语音**: 随机播放战胜语音（奶龙哈哈大笑优先）

#### Boss 2: 「钢铁巨螯」 Iron Claw (第 10 关)
- **外观**: 螃蟹状双炮管巨型坦克，金属色
- **机制**: 双炮台独立瞄准，可伸出钳子近战
- ... (共 6 个 Boss，Solo Builder 可先做 3 个，后续扩展)

#### Boss 通用参数结构
```javascript
const BossTemplate = {
  id: 'egg_emperor',

  width: 120, height: 120,
  // 阶段行为

    { hpThreshold: 0.66, behaviors: ['circular_shot'] },

    { hpThreshold: 0,    behaviors: ['egg_rain', 'charge_rush'] }
  ],
  // 掉落奖励
  rewards: {
    score: 5000,
    upgrades: 3  // 三选一技能次数
  }
};
```

## 九、核心算法伪代码 (Key Algorithms)

### 9.1 游戏主循环 (Game Loop)
```javascript
class Game {
  constructor() {
    this.lastTime = 0;
    this.accumulator = 0;
    this.fixedDt = 1000 / 60;  // 固定步长 16.666ms
  }
  
  start() {
    requestAnimationFrame((t) => this.loop(t));
  }
  
  loop(currentTime) {
    // 1. 计算帧间隔 deltaTime
    const dt = currentTime - this.lastTime;
    this.lastTime = currentTime;
    this.accumulator += dt;
    
    // 2. 固定步长更新逻辑 (最多 catch up 5 帧防死循环)
    let catchUp = 0;
    while (this.accumulator >= this.fixedDt && catchUp < 5) {
      this.update(this.fixedDt);  // 更新实体位置/AI/碰撞
      this.accumulator -= this.fixedDt;
      catchUp++;
    }
    
    // 3. 渲染 (插值可选，先不用)
    this.render();
    
    // 4. 下一帧
    requestAnimationFrame((t) => this.loop(t));
  }
}
```

### 9.2 碰撞检测 (AABB 矩形碰撞)
```javascript
// 优化: 空间分区 (Spatial Grid) —— 只检测同格/相邻格实体
function checkCollision(a, b) {
  return !(a.x + a.width  < b.x ||
           a.x            > b.x + b.width ||
           a.y + a.height < b.y ||
           a.y            > b.y + b.height);
}
```

## 十一、性能优化建议 (Performance Tips)

1. **对象池 (Object Pool)**: 子弹、粒子、爆炸特效反复复用同一组对象，避免频繁 GC
2. **离屏 Canvas**: 静态地图墙块绘制到离屏 Canvas，一次 drawImage 而不是每帧画百个矩形
3. **空间分区**: 碰撞检测使用 `SpatialGrid` (50x50 格子)，O(n²) → O(n)
4. **脏矩形渲染**: 非全屏特效时只重绘变化区域（初期可跳过，全量重绘性能也够）
5. **音频预加载**: 页面加载时 preload 所有语音和音效，首击不延迟
