# 坦克游戏 UI 改进方案

## 参考: Steam 游戏《Minimalist Tower Defense》

### 参考设计分析

| 元素 | 参考做法 | 当前问题 |
|------|----------|----------|
| **配色** | 深灰背景 + 白色文字 + 单色强调 | 6种霓虹色同时使用，视觉混乱 |
| **主菜单** | 极简大标题 + 3个黑线白边按钮 | 5个霓虹色按钮，副标题冗余 |
| **HUD** | 信息密度低，一目了然 | 面板过大，边框装饰过多 |
| **地图** | 网格纹理 + 几何图标 | 白色背景，无战术感 |
| **按钮** | 黑色填充 + 1px白边 | 霓虹边框 + 发光效果 |
| **字体** | 单色粗体，无装饰 | 多层投影+描边+渐变 |
| **升级页** | 简洁卡片 | 稀有度边框发光过度 |

## 一、配色方案重构

### 1.1 色彩系统

```
背景层 (深色):
  BG_DEEP       = (18, 18, 22)      最深底 (替代当前 (16,16,28))
  BG_PANEL      = (28, 28, 34)      面板背景 (替代当前 (30,32,50))
  BG_GRID       = (38, 38, 46)      网格线 (替代当前 (44,46,68))

文字层:
  TEXT_PRIMARY   = (230, 230, 240)   主文字 (亮白)
  TEXT_DIM       = (120, 120, 135)   次文字 (暗灰)
  TEXT_MUTED     = (80, 80, 95)      注释文字

强调色 (仅限 2-3 种):
  ACCENT        = (220, 195, 120)   金色 - 主要强调 (标题/按钮hover)
  SUCCESS       = (120, 200, 140)   暗绿 - 血量/正向
  DANGER        = (200, 85, 85)     暗红 - 警告/危险
```

**原则**: 全局最多 3 种颜色同时出现。强调色只用金色。

### 2.2 标题设计

- **主标题**: 64px 粗体，白色，无装饰 (去除投影/描边)
- **副标题**: 28px 间距字距，`STEEL · FRONTIER`，TEXT_DIM 色
- **字距**: 标题字符间距加大 (tracking 8-12px)

### 2.3 按钮设计

```
按钮规格:
  宽度: 320px
  高度: 64px
  边框: 1px TEXT_DIM (默认) / 1px ACCENT (hover)
  背景: BG_PANEL (默认) / (40,40,48) (hover)
  圆角: 4px (去圆角或极小圆角，直角更硬朗)
  字体: 20px 粗体，TEXT_PRIMARY
  位置: 水平居中，y 从 380 开始，间距 12px
  hover: 背景微亮，边框变金色，文字变金色
```

### 2.4 移除元素

- ❌ 每个按钮的副标题 (太冗余)
- ❌ 霓虹色边框 (CYAN/PINK/PURPLE/YELLOW)
- ❌ 方括号快捷键标记 `[1]` `[2]`
- ❌ 大圆角 (12px → 4px)
- ❌ 发光/投影效果

### 2.5 坦克选择面板

```
坦克面板:
  位置: 左下方 (x=60, y=680)
  宽度: 480px
  高度: 280px (包含坦克展示 + 名称 + 说明)
  边框: 1px TEXT_DIM
  标题: "选择你的坦克" 18px TEXT_DIM
  3D坦克图: 居中显示，200×200
  名称: 24px ACCENT色 (如 "绿色坦克")
  子弹类型: 16px TEXT_PRIMARY (如 "弹药: 飞刀弹")
  操作提示: 14px TEXT_MUTED (底部一行)
  左右切换按钮: 圆形小箭头，x=20 / x=width-20
```

```

  高度: 320px (原 340px)
  背景: BG_PANEL
  边框: 1px (按稀有度: 普通=TEXT_DIM, 稀有=ACCENT, 史诗=金色双环)

```
坦克:

  敌方: 深灰 (40, 40, 48)

  ❌ 霓虹色光圈
